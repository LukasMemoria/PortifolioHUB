# EcoGrow

**Área:** IoT e agricultura  
**Tipo:** proposta de projeto acadêmico/pessoal  
**Ideia central:** apoiar o acompanhamento das condições do cultivo.

## Sobre o projeto

EcoGrow é uma proposta de solução para aproximar tecnologia e agricultura. A ideia é facilitar o acompanhamento do cultivo, reunindo informações úteis para observar mudanças e planejar os cuidados com mais contexto.

## Objetivos iniciais

- Organizar informações sobre as condições do cultivo.
- Tornar o acompanhamento agrícola mais claro e acessível.
- Apoiar a observação da evolução do cultivo e o planejamento da rotina.
