# PortifolioHUB

**Área:** Desenvolvimento web  
**Resumo:** Site estático para organizar e apresentar projetos acadêmicos e pessoais.

## Tecnologias

- HTML5
- CSS3
- Git e GitHub
- GitHub Pages

## Estrutura

A página inicial fica em `index.html`, os estilos em `assets/css/`, a documentação geral em `docs/` e os projetos em pastas próprias dentro de `projetos/`.

## Visualização local

Abra `index.html` diretamente no navegador. Não são necessárias dependências ou ferramentas de build.

## Publicação

O workflow `.github/workflows/pages.yml` implanta a branch `main` no GitHub Pages. A configuração inicial da origem do Pages fica em **Settings → Pages → Build and deployment**.

## Evolução

O site será ampliado conforme novos projetos e informações forem disponibilizados. Atualize este documento junto com mudanças relevantes na estrutura ou nas tecnologias.
